# 📱 СКОМ (CKOM) — Умный учет коммунальных услуг

Современное мобильное приложение на **React Native & Expo** для периодического учета показаний коммунальных счетчиков (электричество, холодная вода, горячая вода, природный газ), автоматического расчета расходов по тарифам (включая социальные нормы) и аналитики затрат.

---

## 🌟 Ключевые возможности

### 1. ⚡ Счетчик и ресурсы
- **Электричество (кВт⋅ч)** — поддержка базового тарифа и социальной нормы (до 200 кВт⋅ч по льготной цене, свыше — по повышенной ставке).
- **Холодная вода (м³)** — фиксация показаний и расчет по тарифам.
- **Горячая вода (м³)** — учет расхода и стоимости подогрева.
- **Природный газ (м³)** — учет кубометров с возможностью сезонных лимитов.

### 2. 🧮 Интеллектуальный ввод показаний и расчет на лету
- Выбор счетчика в 1 касание.
- Автоматическая подстановка предыдущих показаний и даты.
- **Калькулятор реального времени:** при вводе цифр сразу рассчитывается расход ($\Delta$) и точная стоимость к оплате с детальной разбивкой по ступеням тарифа.
- Защита от случайных ошибок: предупреждение, если новое показание меньше предыдущего, и проверка формата даты.
- **Замена счетчика:** если прибор заменили, расход считается от нуля, а запись помечается в журнале и в отчете.
- Поле для заметок (ремонт, отъезд, поверка счетчика).

### 3. 🏷️ Гибкая настройка тарифов
- Настройка стоимости за 1 единицу ресурса.
- **Поддержка ступенчатых тарифов (социальной нормы) до трёх ступеней:**
  - Например, Свет: до 200 кВт⋅ч — `450 сум`, свыше — `900 сум`.
  - Газ: до 500 м³ — `650 сум`, свыше — `1 500 сум`.
  - Третья ступень (второй лимит со своей, самой высокой ставкой) включается переключателем.
- Переключение между дифференцированным и фиксированным тарифом.
- Кнопка быстрого восстановления стандартных тарифов.

### 4. 📋 Журнал и передача показаний в Telegram / SMS
- Полная история всех внесенных показаний с группировкой по месяцам.
- Фильтры по периодам (месяцам) и типам ресурсов.
- **Правка и удаление записей:** любое показание можно исправить (значение, дата, примечание) — расход и сумма пересчитываются, текущее показание счетчика синхронизируется с последней записью.
- **Кнопка «Для инспектора / Скопировать отчет»**:
  Генерирует готовый красивый отчет и копирует его в буфер обмена для отправки в Telegram или SMS контролеру:
  ```text
  📋 Показания счетчиков (СКОМ)
  📅 Период: Сентябрь 2026
  🏠 Объект: Квартира
  ─────────────────────
  ⚡ Электричество:
    • Было: 14 810 | Стало: 14 980
    • Расход: +170 кВт⋅ч
    • Сумма: 76 500 сум
  ...
  💵 ИТОГО К ОПЛАТЕ: 143 700 сум
  ```

### 5. 📊 Аналитика и графики
- Среднемесячные расходы и сравнение с прошлым месяцем (% динамика).
- Наглядный гистограммный график расходов за последние месяцы.
- Круговая структура затрат (доля затрат на свет, воду, газ).
- Умные подсказки по энергоэффективности и экономии.

### 6. ⚙️ Мульти-объекты и настройки
- **Полноценный учет нескольких объектов** («Квартира», «Дача», «Дом родителей»): у каждого объекта свои счетчики, своя история, своя аналитика и свой отчет. Все экраны показывают данные только выбранного объекта.
- Новый объект сразу получает комплект из 4 счетчиков с нулевыми показаниями.
- Объекты можно переименовывать и удалять (вместе со счетчиками и историей); счетчики — добавлять, переименовывать, задавать номер прибора и начальное показание, удалять.
- **Контакты инспекторов** по каждой услуге и объекту (ФИО, организация, телефон, Telegram, примечание — все поля необязательные): кнопка открывает чат инспектора в Telegram или звонок, а после копирования отчета в журнале приложение сразу предлагает открыть чат нужного инспектора.
- Тёмная и светлая темы оформления.
- **Реальные ежемесячные уведомления** (`expo-notifications`) в выбранный день и час: напоминание о контрольном сроке сдачи показаний.
- Резервное копирование **в файл**: `ckom-backup-ГГГГ-ММ-ДД.json` через системное меню «Поделиться» (Telegram, Google Drive, Файлы) и восстановление выбором файла. Копирование/вставка JSON текстом остались как быстрый вариант.
- Валюты расчетов: сум (UZS), ₽ (RUB), $ (USD), ₸ (KZT) — валюта тарифов всегда следует за выбранной.
- Чистый первый запуск: один объект «Uy» с нулевыми счетчиками, никаких демо-данных. Демо-записи, оставшиеся от прежних версий, удаляются автоматически при обновлении (данные пользователя не затрагиваются).
- 100% автономность: данные сохраняются локально (`AsyncStorage`) и доступны без интернета.

## 📦 Готовый офлайн APK (Android)

Сформирован готовый установочный файл приложения:
- 📍 **Путь:** [`d:/django/KCOM/CKOM-v1.0.apk`](file:///d:/django/KCOM/CKOM-v1.0.apk) (или `android/app/build/outputs/apk/release/app-release.apk`; ARM-сборка для смартфонов: `armeabi-v7a`, `arm64-v8a`)
- 📱 **Установка:** Скопируйте файл `CKOM-v1.0.apk` на Android смартфон (через USB-кабель, Telegram или Google Drive) и нажмите для установки. Никакой Expo Go или интернет не требуются — приложение работает 100% автономно!

### Команда для повторной сборки APK:
```bash
npm run build:apk
```

> ⚠️ **Сборка требует JDK 17.** Если `JAVA_HOME` указывает на JBR из Android Studio (JDK 24/25), сборка падает на шаге
> `configureCMakeRelWithDebInfo` с сообщением `WARNING: A restricted method in java.lang.System has been called` —
> AGP принимает предупреждение новой JVM за ошибку. Решение: указать JDK 17, например
> ```bash
> cd android && ./gradlew.bat assembleRelease "-Dorg.gradle.java.home=C:\Program Files\Eclipse Adoptium\jdk-17.0.20.8-hotspot"
> ```
> или прописать `org.gradle.java.home` в `android/gradle.properties` (значение теряется после `expo prebuild`).

> ⚠️ После добавления библиотек с нативным кодом папку `android/` нужно пересоздать командой
> `npx expo prebuild --platform android`, иначе разрешения из конфиг-плагинов (например `POST_NOTIFICATIONS`)
> не попадут в `AndroidManifest.xml`. Файл `android/local.properties` после prebuild придется создать заново
> (`sdk.dir=C:/Users/<имя>/AppData/Local/Android/Sdk`).

## 🚀 Запуск проекта для разработки

### 1. Запуск сервера разработки Expo
```bash
npx expo start
```
или
```bash
npm start
```

После запуска в терминале появится **QR-код**:
- **На смартфоне Android / iOS:** установите бесплатное приложение **Expo Go** из Google Play / App Store и отсканируйте QR-код камерой. Приложение мгновенно откроется на телефоне!

### 2. Запуск в браузере на ПК (Web)
```bash
npm run web
```
или
```bash
npx expo start --web
```

### 3. Проверка типов и кода
```bash
npx tsc --noEmit
npx expo-doctor
```

## 🛠 Технологический стек
- **Expo SDK 57**
- **React Native 0.86**
- **TypeScript**
- **AsyncStorage** (локальная база данных)
- **Expo Vector Icons** (Ionicons)
- **Expo Clipboard** (мгновенный экспорт отчетов)
- **Expo Notifications** (ежемесячные напоминания)
- **Expo File System + Sharing + Document Picker** (резервные копии файлом)
- **React Native Safe Area Context** (адаптация под все экраны и вырезы)

> ⚠️ Уведомления и выбор файлов требуют нативного модуля: после добавления этих библиотек приложение нужно пересобрать (`npm run build:apk` или `npx expo run:android`). В Expo Go на Android локальные уведомления не работают.

## 🧭 Навигация

Приложение использует собственный таб-переключатель, а не Expo Router: активная вкладка хранится в `useState` внутри `App.tsx`, панель вкладок — `src/components/CustomTabBar.tsx`, экраны получают навигацию через props. Подробнее — в `AGENTS.md`.
